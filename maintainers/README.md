# Maintainer documentation

These repository-only guides are excluded from the npm package.

- [AGENTS.md](../AGENTS.md) defines the non-negotiable repository and agent contract.
- [Architecture](architecture.md) defines stable package, dependency, runtime, extension, configuration, and asset boundaries.
- [Development](development.md) covers local setup, source execution, debugging, focused verification, and platform interpretation.
- [Upstream synchronization](upstream-sync.md) is the executable procedure for reviewing and adopting an upstream release tag.
- [Delta rationale](delta.md) records the human admission case, verification, and exit criteria for each upstream delta unit.
- [Upstream baseline manifest](upstream.json) is the machine-readable canonical baseline, ownership registry, and budget record.
- [Governance baseline](governance-baseline.md) records the historical governance closeout snapshot and remaining priorities.
- [Release](release.md) covers distribution versioning, package review, publishing, and tagging.
