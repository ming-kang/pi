# v0.87.0 synchronization review

This records the adoption decisions for upstream `v0.87.0` (commit `16787ad5b`, coding-agent tree `e0fcee077666`) from the `v0.86.1` baseline. Durable rules stay in [Architecture](../architecture.md); per-path intent stays in the ledger.

Reviewed all 68 coding-agent paths changed from `v0.86.1` to `v0.87.0`:

| Paths | Decision |
| --- | --- |
| 18 runtime source paths clear of deviations | Adopted verbatim: `src/core/session-manager.ts` (`ContextEditEntry`, `buildSessionProjection()`, `appendContextEdit()`, retain-none `appendCompaction()`), `src/core/compaction/compaction.ts` (projection-based cut points and `estimateProjectedContextTokens()`), `crash-log.ts`, `cache-warmer.ts`, `prompt-templates.ts`, `provider-composer.ts`, `core/index.ts`, `cli/file-processor.ts`, `main.ts`, `utils/mime.ts`, `utils/tool-result-images.ts`, `modes/interactive/bug-report.ts`, `components/tree-selector.ts`, `export-html/template.js`, and the four `experimental/services/*` files. The service files use chord `0.87.0`'s `change()`/`replace()`, so they had to land with the dependency upgrade. |
| `src/core/agent-session.ts` | Merged upstream's canonical-projection model into the registered `bugfix` deviation. 31 of the 42 upstream hunks applied mechanically; the 11 that overlap BackgroundSession code were merged by hand: `_persistMessage()` returns the entry ID and records it for boundary events and recovery omissions; `_emitAgentSettled()` holds the Background delivery pause across runs deferred from `agent_settled`; `prompt()` defers behind settled handlers before its Background retry and keeps nextTurn context queued until persistence (upstream clears it eagerly); `_appendCustomMessage()` persists, refreshes the projection, then acknowledges Background delivery; compaction, retry, tree navigation, and bash flushes call `_refreshFinalizedContext()` instead of assigning `agent.state.messages`. `getContextSnapshot()` now reads `buildSessionProjection()` instead of the inspection cache. |
| `src/core/sdk.ts`, `src/core/agent-session-runtime.ts` | Merged: `initialState.messages` restores an existing session and `session.refreshContext()` replaces the `agent.state.messages` assignment after `newSession` setup. `executionRole`, `ContextSnapshotCapture`, and the Background pauses stay. |
| `src/core/extensions/{index,runner,types}.ts`, `src/core/index.ts`, `src/index.ts`, `src/core/model-config.ts`, `src/core/resource-loader.ts`, `src/core/tools/read.ts`, `src/modes/interactive/interactive-mode.ts` | Three-way merged without conflicts on top of the registered deviations: boundary events and `emitBoundary()`, `context_with_system`, the `inputLimits` schema, prompt-template diagnostics aggregation, the model resize profile in `read`, crash extension hints, and boundary-compaction rendering. |
| `src/extensions/btw/agent.ts` | Distribution-owned extension migrated from the removed `shouldStopAfterTurn` option to `finishTurn`: error and aborted responses return `undefined`, the step or context limit returns `{ action: "end" }`, and the step budget still counts only answered turns. |

Dependency-carried behavior: `pi-agent-core` `0.87.0` removes `shouldStopAfterTurn` and adds `prepareRequest`, `finishTurn`, and `Agent.peekQueuedMessages()`, all of which `AgentSession` now uses; `pi-ai` `0.87.0` adds `Model.inputLimits` and stops defaulting unknown OpenAI-compatible endpoints to strict tool schemas (#9816); `chord` `0.87.0` replaces mutable `state`/`publish()` with `change()`/`replace()`; `pi-tui` `0.87.0` centers the alt-screen scroll indicator.

Ledger: no entries were added or retired. `src/core/agent-session.ts` intent was rewritten for the projection model. [Architecture](../architecture.md) gained the snapshot-source rule and the settled-handler Background pause.

Validation on Windows: `npm run check`, the focused batch (28 files: the 4 new upstream tests, the 14 adopted or merged upstream tests, and the deviation-covering `context-snapshot`, `btw-extension`, `agent-session-background`, `agent-session-runtime-events`, `sdk-stream-options`, compaction, retry, and prompt suites), the full isolated suite (342 files and 3282 tests passed; 7 files and 88 tests skipped without API keys), the baseline gate (`npm run diff:upstream -- --check`: 511 worktree differences against v0.87.0 with 63 registered deltas, none unregistered or stale), a clean build, and a clean installation of the packed tarball (`PI_PACKAGE_ALLOW_FRESH=1`, since 0.87.0 is younger than the repository's two-day release age) passed. Interactive acceptance in a real TTY is assigned to the owner: a `turn_end` or `agent_before_settle` handler that appends entries and continues (the boundary-compaction rendering path in `entry_appended`), `/tree` and `/export` showing `context_edit` entries after an auto-retry, a `/bug` attempt in `--offline` mode, the crash extension hint, and BTW after a compaction.
