# Upstream v1.0.2

Adopted `earendil-works/pi` release `v1.0.2` (`cd32f7725fdbddbaecdff5b1e68491563394e0ca`), including `v1.0.1`, from the recorded `v1.0.0` baseline. Synchronization started from `193b5c3612ad345ebb1a2fa845df2249410f6807` on `sync/upstream-v1.0.2`. The root package stayed at `1.0.0` during synchronization; the owner then requested publication as `@astralyn/pi@1.0.1`.

## Adoption decisions

- Adopt MCP project overrides, Client ID Metadata Documents, sign-in URL copying, independent tool renderer registration, sampling parameters by thinking level, and the CLI model-list fix. Adopt the provider, codemode output-limit, image-conversion, and terminal-scroll fixes through the exact published libraries.
- Adapt the dropped upstream tool component by using the shared `ToolRenderers` type and TUI PNG transcoder. Reuse `Image` instances so refreshes retain their Kitty image IDs. Keep the distribution's marker-and-rail shell, folding rules, and guard against redraws after disposal. The new resolver runs in both interactive mode and HTML export.
- Adopt the 3D Pi logo and Armin animation, and remove the Daxnuts easter egg with the owner's explicit approval. The new animation entry uses a static import under repository source policy.
- Keep `npm-shrinkwrap.json`, exact dependency pins, and existing dependency scopes. The upstream npm-to-pi.dev migration notice is inapplicable to this pinned distribution, so it remains absent. The shrinkwrap is now distribution-owned rather than an upstream deviation.
- Keep `README.md` and `docs/quickstart.md`: upstream's installer, Nix distribution, and session-sharing promotion do not describe this package. The `docs/cli.md` addition only documents that upstream Nix installation, so it is not ported. Port the behavioral additions into `docs/codemode.md`, `docs/extensions.md`, `docs/keybindings.md`, `docs/mcp.md`, and `docs/models.md`; record user-facing changes in `CHANGELOG.md`.
- Keep `install-lock/` dropped. Upstream's `scripts/build-coding-agent-bundle.mjs` is unchanged in this release window, so the standalone build strategy stays unchanged.

## Dependency review

All ten direct `@earendil-works/*` packages and transitive `pi-telemetry` advance from `1.0.0` to `1.0.2`; Pi AI's nested Anthropic SDK advances from `0.124.0` to `0.129.0`. Resolutions and integrity hashes change only for those twelve packages. No dependency scope or installation script changes. Upstream's new direct `brace-expansion` pin is unnecessary here: the existing `5.0.12` override and shrinkwrap already pin it, and this package has no direct consumer.

The requested latest upstream release was less than two days old. Resolution and installation used command-scoped `--min-release-age=0`, and package verification used `PI_PACKAGE_ALLOW_FRESH=1`. The shrinkwrap was also regenerated with the repository's npm `11.15.0`, with no further changes. An npm hidden-cache inconsistency initially left installed `1.0.0` files; removing only `node_modules/.package-lock.json` and reinstalling restored agreement between declared, locked, and installed versions.

`npm audit` reports five high-severity entries in the unchanged development-only `shx` / `shelljs` / `fast-glob` / `micromatch` / `braces` chain (GHSA-vfj7-8cjw-p6xm). Its offered fix downgrades `shx`; that unrelated change is deferred to dependency maintenance. Production packages are not in this advisory chain.
