# Upstream v1.0.0

Adopted `earendil-works/pi` release `v1.0.0`, which includes `v0.99.2`, from the recorded `v0.99.1` baseline on the standalone `sync/upstream-v1.0.0` branch. The root package stayed at `@astralyn/pi@0.99.0` during synchronization; the owner requested the `1.0.0` release as a separate step.

## Adoption decisions

- Adopt MCP changes: background connection for servers without `direct` tools, the `mcp_servers` system prompt section, server descriptions and `describeNamespace()`, provider-token authentication, `oauth.clientName`, `oauth.authServerMetadataUrl`, RFC 9207 `iss` checks, per-server credential storage, scope-keeping step-up sign-in, and the `-`/`_` name normalization. Adopt leaner codemode descriptions and recovery errors, `models.generateImages()`, Radius and Anthropic copy-code login, Anthropic workload identity federation, `quietStartup: "header"`, `/reload` activation of new `defaultTools`, and the transcript memory, theme, autocomplete, and performance fixes.
- Retire `tui-fullscreen-default`. Upstream now defaults to fullscreen, so the setting, CLI help, and settings description match upstream. The remaining `src/cli/args.ts` help-text change (no plan-mode example, since this distribution removed plan mode) moves to `distribution-identity`.
- Resolve `agent-session.ts` by keeping the Tasks tool activation and `replaceService()` on reload, expressed through upstream's new `_isAllowedTool()` and `_setActiveTools()`, so restored pending tools behave like upstream.
- Adopt upstream's `VisualLinePreview` for collapsed shell output and drop the hand-written result cache it replaces. The shell call component, syntax highlighting, background handoff text, and self-scheduled elapsed timer stay distribution-owned. The shell tool's structured output schema keeps the distribution's equally short descriptions.
- MCP's new wait-for-servers hook identifies codemode and `tool_search` through the existing `pi:discover-tool-orchestrators` event, now in one local helper, instead of importing the other extensions' `isCodemodeTool()` and `isToolSearchTool()`.
- `pi-logo-animation.lazy.ts` imports the animation statically under repository source policy; its signature is unchanged, so `interactive-mode.ts` stays upstream-shaped. It is registered under `distribution-identity` beside the other static-import rewrites.
- Upstream removed the experimental `micro` and `mini` clients; their distribution tool-presentation edits go with them. The new experimental `durable` and `vacation` TUIs and `test/tool-renderer-examples.test.ts` import the distribution's `tool-view/tool-execution.ts`, which has the same constructor, and are registered under `tool-presentation`. Upstream's dropped `components/tool-execution.ts` has no changes in this window.
- `install-lock/` stays dropped. Upstream bundling for the coding-agent package is unchanged since v0.99.1; only monorepo entry-graph budgets and Bun binary smoke tests changed.
- Keep distribution-owned documentation. Take upstream's `mcp.md` with the distribution intro and link targets, add the new `codemode.md` page with a note on the Tasks background handoff result, and port factual changes into `usage.md`, `settings.md`, `extensions.md`, `sdk.md`, `models.md`, `providers.md`, and `environment-variables.md`. The provider page keeps its own section names.

## Dependency review

The owner requested this release explicitly, so npm resolution and package verification used command-scoped release-age exceptions (`--min-release-age=0`, `PI_PACKAGE_ALLOW_FRESH=1`); no global npm configuration changed. All `@earendil-works/*` packages move from `0.99.1` to `1.0.0` with unchanged scopes, including the transitive `pi-telemetry`. `@smithy/core` moves from `3.35.0` to `3.35.1`. Upstream's experimental code and its tests import the new `@earendil-works/pi-durable@1.0.0`, which the monorepo hoists without declaring; it is a development dependency here, like Client, Protocol, and Server, because `src/experimental/` is excluded from the build. No new package has an installation script, and npm audit reported no vulnerabilities.

- `npm run format`, `npm run check`, installed and pinned dependency checks, and `npm run diff:upstream -- --check`.

- Real terminal checks used the offline fixture and a copy with a foreground `bash` prompt: fullscreen startup header, pending, settled, collapsed, and expanded tool rows, the collapsed bash preview and its hint, the background handoff, `/reload`, and `/tree`. Screenshots were inspected.

Logs, screenshots, the fixture copy, and the tarball are retained locally under `.artifacts/upstream-v1.0.0/`. They are ignored build and test artifacts, not published source.
